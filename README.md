# appiumselenium-junit-cucumber-pom
Estructura de trabajo usando lenguaje de programación JAVA, usando SELENIUM, APPIUM con emulador, MAVEN, JUNIT, CUCUMBER(BDD), EXCEL como fuente de datos, ALLURE como reporting.

## ▶️ How to Run

### Prerequisites
- Java JDK 17+
- Maven installed
- Selenium

### Steps
```bash
# Clone the repository
git clone https://github.com/mikeai-lab/appiumselenium-junit-cucumber-pom.git

# Navigate to project
cd appiumselenium-junit-cucumber-pom

# go to the folder src/test/resources/features and execute the desired method for each feature
```
